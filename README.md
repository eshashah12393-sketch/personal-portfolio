Modern High-Impact Developer Portfolio

A sleek, responsive, and modern personal portfolio built with pure web technologies. Designed for high visual impact, extreme readability, and seamless user interaction.

Key Features:
- Heavy UI/UX Aesthetics: Custom glassmorphism, multi-color gradient shimmer headers, and smooth ambient glow backgrounds.
- Micro-Interactions: Responsive 3D hover transforms, neon glow shadows, and snappy scroll-reveal transitions.
- Dynamic PDF Resume: Native @media print integration allowing clean, single-page PDF resume generation directly via browser.
- Web Mail Integration: Direct-to-Gmail web compose flow bypassing native mail-client reliance.
- Fully Responsive and Accessible: Optimized across all desktop and mobile viewports with strict high-contrast readability ratios.

Built With:
- Frontend: HTML5, Modern CSS3 (CSS Variables, Flexbox/Grid, Animations), Pure JavaScript (ES6+)
- Deployment: Vercel (CI/CD via GitHub Integration)
